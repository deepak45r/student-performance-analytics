# Student Performance Analytics System

## 1. Project Overview
The Student Performance Analytics System is a Python-based project that analyses students' academic performance using their subject marks and attendance data.

## 2. Objectives
- Calculate total and average marks for each student.
- Assign grades based on average marks.
- Identify pass and fail students.
- Find the highest and lowest performers.
- Calculate class average marks.
- Analyse subject-wise average performance.
- Display each student's attendance.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- CSV dataset

## 4. Dataset Description
The dataset contains student ID, name, department, marks in Pythone, NumPy and Pandas, and attendance percentage.

## 5. Project Features
- Loads student data into a Pandas DataFrame.
- Uses NumPy for numerical calculations.
- Uses a reusable function to calculate total marks.
- Uses loops and conditional statements to process student records.
- Calculates totals, averages, grades and pass/fail results.
- Identifies top and lowest performers.
- Generates subject-wise averages and an attendance report.

## 6. Grading and Pass/Fail Rules
- A: Average ≥ 90
- B: Average ≥ 75 and < 90
- C: Average ≥ 60 and < 75
- D: Average ≥ 40 and < 60
- F: Average < 40

A student passes if they score at least 40 marks in all three subjects. Otherwise, they fail.

## 7. How to Run the Project
1. Install Python.
2. Install the required libraries using `pip install pandas numpy`.
3. Keep `students.csv` and the Python program in the same folder.
4. Run the Python program using VS Code or a terminal.

## 8. Conclusion
This project demonstrates how Python, Pandas, NumPy, loops, conditional statements and functions can be used to analyse student performance and generate an academic report.
